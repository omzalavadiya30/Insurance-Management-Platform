# Insurance Management Platform

A full-stack web application for managing insurance customers, policies, claims, premiums, documents, and reports.

---

## Tech Stack

### Frontend
- Next.js 15
- TypeScript
- Tailwind CSS
- React Hook Form
- Axios
- Zod
- Chart.js

### Backend
- Node.js
- Express.js

### Database
- Supabase PostgreSQL

### Authentication
- Supabase Auth

### File Storage
- Supabase Storage

### Other Tools
- PDFKit
- Git & GitHub
- Postman

## Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Frontend

```bash
cd client
npm install
npm run dev
```

Runs on

```
http://localhost:3000
```

### Backend

```bash
cd server
npm install
npm run dev
```

Runs on

```
http://localhost:5000
```
